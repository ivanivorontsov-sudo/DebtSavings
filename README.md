# DebtSavings — Долг и накопления

Android-приложение для учёта долга и накоплений с журналом операций и калькулятором кредита.

## Основные возможности

- **Поле ввода + кнопки + / −** — добавляете или вычитаете сумму
- **Крупная сумма внизу** с подписью:
  - положительная → **Накопления**
  - отрицательная → **Долг**
- Валюта: **рубль (₽)**
- **Автосохранение** всех операций
- **Журнал** всех вводов
- Можно **удалить** любой пункт журнала или **отменить** последнюю операцию — сумма пересчитывается
- При долге **≥ 500 000 ₽** — предупреждение о риске банкротства

## Калькулятор кредита (меню)

- Вводите: ставку (% годовых), срок (месяцы), ежемесячный платёж
- Показывает: тело кредита, общую переплату, ежедневные проценты
- **Каждый день** при входе в приложение на долг начисляются проценты
- Платёж уменьшает **тело долга**

## Скачать APK

1. Откройте [Actions](https://github.com/ivanivorontsov-sudo/DebtSavings/actions)
2. Дождитесь workflow **Build APK**
3. Скачайте артефакт `debt-savings-debug` → внутри `app-debug.apk`
