# DebtSavings — Долг и накопления

Android-приложение для учёта долга, накоплений, кредитов (модель WB Кэш) и подписок.

**v1.1** · пакет `com.example.debtsavings`

## Возможности

- Журнал операций, несколько кредитов, накопительный счёт
- Тело / начисленные проценты / комиссии — **отдельные поля**
- Мин. платёж с разбивкой; авто-учёт в срок (по умолчанию)
- Платёж: комиссии → проценты → тело (превью в диалоге)
- Шаблон «WB Банк»
- **Подписки**: цена, период, дата, режим «Надо оплатить» / «Надо отключить», напоминания за 7/3/1 дн.

## Модель WB Кэш (приближение)

Это **личный трекер**, не выписка банка. Тарифы ориентировочно по условиям WB (≈ авг. 2026).

| Режим | Начисление |
|-------|------------|
| Грейс (`graceMode`) | Нет %% на тело. В конце календарного месяца: комиссия **50 ₽ × ceil(тело/1000)** (минимум 50 ₽). Пропуск в 1-й месяц, если договор после 21-го. |
| Вне грейса | Простые %%: `тело × ставка%/100 / 365 × дни` → в `accruedInterest` (тело не растёт). Ставка по умолчанию **59.8%**. |

**Мин. платёж** ≈ `комиссии + (accruedInterest / 12) + доля_тела`, где доля тела = 0% или `max(floor(тело×%/100 до 100 ₽), пол 500 ₽)` при share 3%/10%.

**Погашение суммы:** комиссии → проценты → тело. Авто-мин. применяется в/после `nextMinPaymentDue`, если включено.

Все поля вручную редактируются.

## Подписки

Меню → **Подписки**. Категории (выбор опции):
1. **Уведомления по карте** — SMS/push банка
2. **Страховка по долгу / кредиту** — часто режим «Надо отключить»
3. **Увеличенные лимиты в банке** — платный буст лимита
4. **Сторонние сервисы** — стриминг, VPN, облако

Шаблоны в диалоге «Шаблоны подписок». Напоминания за 7/3/1 день — оплатить или отключить.

Уведомления через AlarmManager (как проценты). Нужно разрешение `POST_NOTIFICATIONS` (Android 13+).

## Миграция данных

Старые кредиты в SharedPreferences без новых ключей: `accruedInterest=0`, `accruedFees=0`, `graceMode=false`, `autoApplyMinPayment=true` и т.д.
