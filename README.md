# DebtSavings — Долг и накопления

Android-приложение для учёта долга и накоплений с **несколькими кредитами** и журналом операций.

## Возможности

- Поле ввода + кнопки **+** / **−**
- Крупная сумма: **Накопления** (зелёная) или **Долг** (красная), валюта ₽
- **Привязка каждой операции к кредиту** — выпадающий список при вводе
- Несколько кредитов: название, ставка, срок, платёж, тело долга
- Автосохранение, журнал, отмена последней / удаление пункта
- Ежедневное начисление процентов **по каждому кредиту** отдельно
- Платёж уменьшает тело выбранного кредита
- Предупреждение при долге ≥ 500 000 ₽

## Как пользоваться

1. **Меню → Мои кредиты** — добавьте один или несколько кредитов (+)
2. На главном экране выберите кредит в списке «Привязать к кредиту»
3. Введите сумму и нажмите **+** (пополнение/платёж) или **−** (увеличение долга)
4. Операция попадёт в журнал с пометкой кредита
5. Каждый день при открытии приложения проценты начисляются автоматически
